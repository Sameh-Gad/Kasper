<h1 align="center">Kasper - Modern Agency Template</h1>

<p align="center">
  A fully responsive, modern portfolio and agency template built with pure HTML and CSS. This project demonstrates strong fundamentals in web layout, responsive design, and clean UI architecture.
</p>

## 🔗 Live Demo
Check out the live project here: [Kasper Live Preview](https://kasperagency.netlify.app/)

## ✨ Key Features
* **Fully Responsive:** Beautifully adapts to desktop, tablet, and mobile screens.
* **Modern UI/UX:** Clean and professional layout suitable for digital agencies.
* **Semantic HTML5:** Clean, accessible, and SEO-friendly markup.
* **Pure CSS3:** Built without frameworks, relying on Flexbox, CSS Variables, and custom styling.

## 🛠️ Technologies Used
* **HTML5**
* **CSS3**
* **FontAwesome** (Icons)
* **Google Fonts**

## 💡 What I Learned
Through this project, I solidified my understanding of CSS positioning, creating responsive navigation bars, structuring complex layouts using Flexbox, and managing global CSS variables for consistent theming.
